REQUIREMENTS

Ubuntu 22.04 or newer. Debian works too. Boost 1.74 or newer is required. An old machine is fine.

DEPENDENCIES 
$ sudo apt-get install -y build-essential cmake \
    libboost-filesystem-dev libboost-system-dev \
    libboost-thread-dev libboost-program-options-dev \
    libssl-dev libleveldb-dev nlohmann-json3-dev

INSTALL

BUILD AND START 
$ git clone https://github.com/natusor/MONEU.git
$ cd MONEU
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j$(nproc)
$ ./build/src/moneu-test-noise
$ ./build/src/moneud -daemon

The tests end with ALL TESTS PASSED. The node takes about ten minutes to catch up.

Delete any old build folder before you start. CMake works from a clean slate.

WALLET

Write down the twenty four words it prints. Use the same password for both commands. Building the noise file takes a few minutes and works the machine hard on purpose.

WALLET COMMANDS 
$ ./build/src/moneu-cli createwallet "your-password"
$ ./build/src/moneu-cli makenoise "your-password"
$ ./build/src/moneu-cli walletunlock "your-password"
$ ./build/src/moneu-cli getnewaddress

MINING

MINING COMMANDS 
$ ./build/src/moneu-cli startmining YOUR-ADDRESS 2
$ ./build/src/moneu-cli getmininginfo

You can also run it through Tor SOCKS on 127.0.0.1:9050.

NODES

A node that never mines a block is still useful. Many small machines hold the network up better than a few big ones.

Start it and leave it alone. Nothing else is needed.

CARE

  • Copy the wallet folder to two drives and encrypt them. The noise file is in there. Lose it and the coins are gone. The twenty four words will not help.
  • Build the noise file on a real machine. Not a virtual one. The node checks the quality first and will say so.
  • One wallet per machine. Never two.
  • Keep an eye on the leaf counter. When it gets low make a new wallet on another machine and send the coins there.
  • Every input you spend burns four leaves. Sending one big payment costs you much less than sweeping up twenty small ones.

SHIELD

MONEU guards your coins. Only you can send them. Even somebody with a quantum computer who works out your private key cannot move anything. They would need your noise file and only you have that.

Keep it on a drive you unplug. Plug it in when you pay somebody and unplug it after.

The interesting part is not who finds blocks fastest. It is who builds the better source of noise.

The rules do not check where the entropy came from. Only that the proof holds. So you can build a better collector without breaking anything for anyone else.

CONFIG

Put this in ~/.moneu/moneu.conf before the first start.

CONFIG FILE 
rpcuser=moneu
rpcpassword=PUT-A-LONG-RANDOM-STRING-HERE
rpcbind=127.0.0.1
rpcport=8328
rpcallowip=127.0.0.1

port=8327
listen=true
upnp=false

dbcache=450
txindex=true

loglevel=info
logtofile=true
maxlogsize=10
logips=false

Make the password with this and then lock the file down.
