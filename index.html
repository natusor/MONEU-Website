NODES

Start your MONEU node and mine solo.

CARE

Build from a clean slate and delete any old build folder first. When the tests say ALL TESTS PASSED the node is ready. Write down the twenty four words the wallet prints and use the same password for the wallet and for the noise file. Building that file takes a few minutes and works the computer hard on purpose so build it on a real machine and not on a virtual one.

Copy the whole wallet folder to another drive with the noise file included. The seed phrase alone will not bring your coins back without it. Keep one wallet per computer and watch the leaf counter: every payment uses four leaves out of the 1 048 576 your computer made so the file is good for 262 144 payments. When it runs low make a wallet on another computer and send the coins there.

Leave the rpcpassword line out and the node makes a random one for you. If you set your own make it long and lock the file down. The node can run through Tor if you want it to.

SHIELD

Only you can send your coins. If somebody works out your private key even with a quantum computer they still cannot move anything without your noise file and that file never leaves your computer.

You can keep it on the same drive as the node or copy it to an external drive and plug that in only when you pay somebody.

Anyone can build an external device that collects entropy and feed it into their wallet.
