REQUIREMENTS

Ubuntu 22.04 or newer. Debian works too. Boost 1.74 or newer is required. An old computer is fine.

DEPENDENCIES
$ sudo apt-get install -y build-essential cmake \
    libboost-filesystem-dev libboost-system-dev \

    libssl-dev nlohmann-json3-dev

INSTALL

BUILD AND START
$ git clone https://github.com/natusor/MONEU
$ cd MONEU
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j$(nproc)
$ ./build/src/moneu-test-noise
$ ./build/src/moneud -daemon

WALLET

WALLET COMMANDS
$ ./build/src/moneu-cli createwallet "your-password"
$ ./build/src/moneu-cli makenoise "your-password"
$ ./build/src/moneu-cli walletunlock "your-password"
$ ./build/src/moneu-cli getnewaddress
$ ./build/src/moneu-cli getwalletinfo
$ ./build/src/moneu-cli getbalance YOUR-ADDRESS

MINING

MINING COMMANDS
$ ./build/src/moneu-cli startmining YOUR-ADDRESS 2
$ ./build/src/moneu-cli startmining YOUR-ADDRESS gpu
$ ./build/src/moneu-cli getmininginfo
$ ./build/src/moneu-cli getwalletinfo
$ ./build/src/moneu-cli getbalance YOUR-ADDRESS
$ ./build/src/moneu-cli stopmining

NODES

Start your MONEU node and mine solo.

CARE

Build from a clean slate and delete any old build folder first. When the tests say ALL TESTS PASSED the node is ready and takes five to ten minutes to catch up with the network. Write down the twenty four words the wallet prints and use the same password for the wallet and for the noise file. Building that file takes a few minutes and works the computer hard on purpose, so build it on a real machine and not on a virtual one.

Copy the whole wallet folder to another drive, noise file included. The seed phrase alone will not bring your coins back without it. Keep one wallet per computer and watch the leaf counter: every payment uses four leaves out of the 1 048 576 your computer made, so the file is good for 262 144 payments. When it runs low, make a wallet on another computer and send the coins there.

Leave the rpcpassword line out and the node makes a random one for you. If you set your own, make it long and lock the file down. The node can run through Tor if you want it to.

SHIELD

Only you can send your coins. If somebody works out your private key even with a quantum computer they still cannot move anything without your noise file and that file never leaves your computer.

You can keep it on the same drive as the node, or copy it to an external drive and plug that in only when you pay somebody.

Anyone can build an external device that collects entropy and feed it into their wallet.
