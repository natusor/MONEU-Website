REQUIREMENTS

Ubuntu 22.04 or newer. Debian works too. Boost 1.74 or newer is required. An old computer is fine.

DEPENDENCIES 
$ sudo apt-get install -y build-essential cmake \
    libboost-filesystem-dev libboost-system-dev \
    libboost-thread-dev libboost-program-options-dev \
    libssl-dev libleveldb-dev nlohmann-json3-dev

INSTALL

BUILD AND START 
$ git clone https://github.com/natusor/MONEU.git
$ cd MONEU
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j$(nproc)
$ ./build/src/moneu-test-noise
$ ./build/src/moneud -daemon

The tests end with ALL TESTS PASSED. The node synchronises with the network in about five to ten minutes.

Delete any old build folder before you start. CMake works from a clean slate.

WALLET

Write down the twenty four words it prints. Use the same password for both commands. Building the noise file takes a few minutes and works the computer hard on purpose.

WALLET COMMANDS 
$ ./build/src/moneu-cli createwallet "your-password"
$ ./build/src/moneu-cli makenoise "your-password"
$ ./build/src/moneu-cli walletunlock "your-password"
$ ./build/src/moneu-cli getnewaddress

MINING

MINING COMMANDS 
$ ./build/src/moneu-cli startmining YOUR-ADDRESS 2
$ ./build/src/moneu-cli getmininginfo

NODES

Start your MONEU node and mine solo.

CARE

  • Copy the whole wallet folder with the noise file inside to another drive. If you lose the noise file then the seed phrase will not recover access to your coins.
  • Build the noise file on a real computer and not on a virtual one. The node checks the quality first and will tell you if it is not good enough.
  • Keep one wallet per computer and never two.
  • Watch the leaf counter. When it runs low make a new wallet on another computer and send the coins there.
  • Every coin you spend uses up four leaves. One coin takes four, twenty coins take eighty. Your computer builds a noise file holding 1 048 576 leaves, which is enough for 262 144 payments.

SHIELD

Only you can send your coins. If somebody works out your private key even with a quantum computer they still cannot move anything without your noise file and that file never leaves your computer.

You can keep it on the same drive as the node, or copy it to an external drive and plug that in only when you pay somebody.

Anyone can build an external device that collects entropy and feed it into their wallet.

CONFIG

Put this in ~/.moneu/moneu.conf before the first start.

CONFIG FILE 
rpcuser=moneu
rpcpassword=PUT-A-LONG-RANDOM-STRING-HERE
rpcbind=127.0.0.1
rpcport=8328
rpcallowip=127.0.0.1

port=8327
listen=true
upnp=false

dbcache=450
txindex=true

loglevel=info
logtofile=true
maxlogsize=10
logips=false

Make the password with this and then lock the file down.

PASSWORD AND PERMISSIONS 
$ openssl rand -base64 32 | tr -dc 'a-zA-Z0-9' | head -c 32
$ chmod 600 ~/.moneu/moneu.conf
